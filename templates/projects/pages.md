# Score the project

Part of the [Projects setup](README.md).

Each tab and feature of a Project has a Quality, Speed and Consumption page and a process map. The Claude side is Claudius's [20 Code Project pages](https://github.com/Colorado-Startups/claudius/blob/main/templates/claude/code-project/README.md#pages). This repo holds the GitHub side.

| Project tab or feature | Map here | What it scores |
|---|---|---|
| Threads, Pull requests and auto-fix | [`delivery`](../../pages/maps/delivery.json) | A thread's branch, draft pull request, CI, review and merge |
| Conversation | [`board`](../../pages/maps/board.json) | A feature, from its card to Done |
| Tracking | [`triage`](../../pages/maps/triage.json) | A bug or quick fix, from intake to its linked pull request |
| Context, Library and artifacts | [`document`](../../pages/maps/document.json) | A doc, from write to read |
| Network secrets | [`secure`](../../pages/maps/secure.json) | Keys, scans and alerts |
| Usage | `spend`, in [Compute Crafter](https://github.com/SoulCraft-Org/compute-crafter/blob/main/maps/spend.json) | Free allowances first, use read the same day |
| Memory, Plugins, Allow cards, Projects list, the rest | Claudius only | No GitHub side |
