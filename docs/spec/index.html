Purpose

Git Crafter holds the rules, templates and guards for repos that AI agents run (AGENTS.md, read 2026-11-25). It is built for Claude Code and OpenCode, on open-source or open-weight repos (README.md, read 2026-11-25).

It gives each repo two public pages, a Quality, Speed and Consumption page and a Process page, so the repo's state stays visible after the first day (README.md, read 2026-11-25).

The owner set the aim in chat on 2026-11-02: the highest-quality build and product, built as fast as possible, with as few tokens as possible (goals.json, read 2026-11-25).

The owner's decision, made 2026-11-25

Git Crafter is built for adopters first.

The product is the repo-level core: Quality page, Process page, CI standard and starters. Org, user and enterprise levels become optional packs or leave for a private overlay.

OptionResult
A. Adopters first (chosen)The repo-level core is the product.
B. The owner's whole stackNot chosen. Today's course changes.
C. Split in twoNot chosen.

Why A: the README and AGENTS.md describe starters for any repo, while 35 of 98 open issues build levels for one owner's accounts.
